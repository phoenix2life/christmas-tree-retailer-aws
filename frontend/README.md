# Frontend

Minimal static HTML/CSS/JavaScript UI.

## Local Demo

Open `index.html` in a browser.

If `API_BASE_URL` is empty in `config.js`, the UI uses local in-browser sample data for reviewer/demo purposes.

## Deployed Demo

After deploying the API, set `API_BASE_URL` in `config.js` to the API Gateway base URL, then upload frontend files to the S3 frontend bucket.
